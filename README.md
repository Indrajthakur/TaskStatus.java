# TaskStatus

A simple task manager for organizing coursework and personal work. Create, edit, complete, filter, and delete tasks, with optional branch, semester, and section details. Tasks are saved in your browser's local storage, so this version works locally without a database service.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally http://localhost:5173).

To create a production build, run `npm run build`.
